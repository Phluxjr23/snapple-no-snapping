# snapple, no snapping!!

removes *"play AI video"* buttons from [snapple facts](https://www.snapplefacts.film/)

# install
i'm working on getting it on mozilla extensions, but for now, go to [debugging](about:debugging) (about:debugging in your address bar) in firefox, clone this repo, and add the manifest.json in *"This Firefox/LibreWolf"* → *"Load temporary Add-on"*
